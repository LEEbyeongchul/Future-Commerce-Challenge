## 해결하려는 문제와 AI가 하는 일 (3–5문장)

마음에 드는 룩을 핀터레스트에 저장하고 인스타에서 캡처하지만, 옷을 하나씩 찾고 여러 쇼핑몰에서 사이즈와 예산을 맞춰 결제하는 과정이 길어서 대부분 갤러리에 쌓인 채로 끝납니다. snap to buy는 사용자가 모아둔 룩 사진과 핀·인스타 게시물로 취향을 배우고, 새 룩을 보내면 AI 에이전트가 아이템을 나눠 출처 링크 → 국내 쇼핑 검색 → 해외 이미지 검색 순서로 원본을 먼저 찾습니다. 원본이 없거나 예산을 넘으면 모은 룩으로 학습한 "내 감성"에 맞는 후보를 성별 사이즈표·실측·반품 이력과 아이템별 예산에 맞춰 조합합니다. 사용자가 총액을 보고 한 번 승인하면 AIR 위임장(한도·허용 쇼핑몰·15분) 범위 안에서 Minds가 여러 쇼핑몰 주문을 대신 실행하고, 사지 않은 아이템의 가격 하락과 품절 임박을 계속 지켜봅니다.
