## 5. 예상 질문 답변 메모

**구글 렌즈랑 뭐가 달라요?**
렌즈는 찾아주는 데서 끝나요. 우리는 사이즈와 예산을 맞추고, 대체 후보를 고르고, 결제까지 대신하는 에이전트예요.

**LLM으로 다 하나요?**
아니요. LLM은 API로 쓰고 요청 이해, 도구 호출, 이유 설명만 맡겨요. 이미지 매칭과 예산 계산은 전용 모델과 알고리즘으로 처리해서 빠르고, 상품이 늘어도 비용이 적게 들어요.

**진짜 실현 가능해요?**
추천까지는 지금 기술로 바로 돼요. 대리 결제는 쇼핑몰 제휴가 필요해서 단계적으로 가요. 에이전트 쇼핑이 늘면 쇼핑몰도 검증된 에이전트(AIR Agent)의 주문을 받게 될 거예요.

**법적으로 괜찮아요?**
장바구니 담기와 구매 링크는 지금 바로 가능해요. 대리 결제는 돈을 직접 받지 않는 구조로, 제휴 쇼핑몰의 공식 API를 통해, 사용자가 정한 한도 안에서 최종 확인 후 진행해요. 국내에서는 원화 PG로 결제하고, AIR는 권한과 신원 확인 중심으로 써요.

**사이즈는 어떻게 맞춰요?**
상품 실측표를 나한테 잘 맞았던 옷의 실측과 비교해요. "작아서 반품" 이력이 있으면 한 치수 올리고, 쓸수록 정확해져요.

**개인정보는요?**
체형과 배송지는 필요한 만큼만 공개하고(AIR Identity), LLM에는 이름이나 연락처 없이 필요한 정보만 보내요. 한도를 넘는 결제는 항상 사용자 확인을 거쳐요.

**한 번에 사는 게 부담스럽지 않나요?**
결제 방식을 고를 수 있어요: 한 번에 결제, 골라서 결제, 장바구니에만 담기, 가격 내려가면 사기.
